接入向导

源码零改动，仅调整启动参数或构建参数
1选择语言
2生成接入配置
3重启服务
4确认探针注册
无需重新编译，也无需改动任何源码
JaCoCo 在类加载时做字节码插桩。注意：探针必须随 JVM 启动加载，不支持对已运行的进程动态挂载。sessionid 是实例自报的构建版本，不配它则增量覆盖率不可用。
java -javaagent:/opt/probe/jacocoagent.jar=\
       includes=com.shop.*,\
       output=tcpserver,address=*,port=6300,\
       sessionid=$(git rev-parse HEAD) \
     -jar order-service.jar
探针端口无鉴权机制
6300 端口不提供任何认证。请仅绑定内网地址，并通过 NetworkPolicy 限制来源。当前平台仅支持测试环境接入。
需要重新编译一次带插桩的产物，但业务源码一行不改
Go 编译为原生机器码，运行期没有可供改写的中间表示。探针文件与 main 同包、由 build tag 守卫，init() 自动执行，业务代码不 import 也不调用任何东西；不带 tag 的生产构建里它根本不参与编译。
# 1. 带插桩构建。-covermode=atomic 是硬要求：清零用的 ClearCounters() 只在 atomic 下可用
go build -cover -covermode=atomic -tags=goverage -o inventory-svc .

# 2. 启动。COVERAGE_BUILD_ID 等价于 JaCoCo 的 sessionid，是增量口径的前提
COVERAGE_ADDR=127.0.0.1:6400 \
COVERAGE_BUILD_ID=$(git rev-parse HEAD) ./inventory-svc
需要重新编译；探针靠构造函数自动启动，不用信号
探针是独立编译单元，全局对象的构造函数早于 main 执行，业务代码不 include 也不调用它任何东西。不依赖 LD_PRELOAD 与 SIGUSR1，Windows 上同样可用；正常构建不编译这个文件。
# 1. 业务代码插桩、探针不插桩。工作目录须是源码根（.gcno 记的是相对源码名），
#    对象文件须用绝对路径（.gcda 的落点是编译期写死进产物的）
g++ -std=c++17 -O0 -g --coverage -c order.cpp -o /build/obj/order.o
g++ -std=c++17 -O0            -c coverage_agent.cpp -o /build/obj/coverage_agent.o
g++ -o match-engine /build/obj/order.o /build/obj/coverage_agent.o --coverage

# 2. 启动。GCOV_PREFIX 每实例一个目录，否则两个实例往同一个 .gcda 互相覆盖
GCOV_PREFIX=/var/cover/match-eng-1 GCOV_PREFIX_STRIP=99 \
COVERAGE_DATA_DIR=/var/cover/match-eng-1 COVERAGE_ADDR=127.0.0.1:6500 \
COVERAGE_BUILD_ID=$(git rev-parse HEAD) ./match-engine
需要重新编译；源码与 Cargo.toml 均零改动
探针是单独编译的目标文件，构建时经 -C link-arg 注入，靠启动期自动执行的构造函数拉起，业务代码里没有任何一处提到它。既没走连续同步模式（%c），也没引入 minicov 依赖。Windows 上须编成 msvc 目标：官方只给 msvc 发 profiler_builtins。
# 1. 探针单独编成 .o，经 link-arg 注入；Cargo.toml 一行不动
gcc -c coverage_agent.c -o /build/obj/coverage_agent.o
RUSTFLAGS="-C instrument-coverage -C link-arg=/build/obj/coverage_agent.o" \
  cargo build --release

# 2. 启动。每实例一个 profraw，且必须是字面路径 —— %p / %m 之类的模式由 LLVM 展开，
#    探针按同一个字符串删不到旧文件，交回的就是历次累计的叠加，界面上看不出异样
LLVM_PROFILE_FILE=/var/cover/svc-1.profraw COVERAGE_ADDR=127.0.0.1:6600 \
COVERAGE_BUILD_ID=$(git rev-parse HEAD) ./target/release/svc
